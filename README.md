# Telegram-магазин (демо)

Бот-магазин: каталог із категоріями, фото й цінами, пошук, кошик, оформлення замовлення з чеком, адмін-панель прямо в Telegram.

## Можливості
- Покупець: каталог, пошук без урахування регістра (укр/рос), кошик (+/−), замовлення (імʼя, телефон кнопкою, адреса, фото чека), «Мої замовлення».
- Адмін (`/admin`): нові/усі замовлення зі зміною статусу (покупець отримує повідомлення), додавання категорій і товарів, «немає в наявності», видалення.
- Адміну приходить сповіщення про кожне нове замовлення разом із чеком.
- Ціни в замовленні фіксуються на момент покупки.

## Запуск
```
pip install -r requirements.txt
set BOT_TOKEN=токен_від_BotFather
set ADMIN_IDS=ваш_telegram_id
python bot.py
```
База — SQLite-файл `shop.db` (змінюється через `DB_PATH`). Для сервера: systemd-юніт або Docker із цією ж командою.

## Тести
`pytest` — 9 тестів: шар даних (кошик, замовлення, пошук, статуси) і наскрізний сценарій «купив → адмін змінив статус» на підміненому Telegram.

Стек: Python 3.13, aiogram 3, SQLite.
